# いのちめぐる苔庭

苔が芽吹いては消え、長く生きた苔には花が咲く。

ライフゲーム（コンウェイのライフゲーム）を、枯山水の苔庭に見立ててながめる鑑賞アプリです。

- 白砂の上で、苔がライフゲームのきまりにしたがって生まれたり消えたりします。生まれたての苔は明るい若草色で、長く生きた苔には花が咲きます。
- 種は「ばらまき」「R-ペントミノ」「どんぐり」「うさぎ」「ダイハード」「グライダーの群れ」「振動子の花壇」「グライダー銃」から選ばれます。
- 庭が静かになったり、同じ形をくり返したり、いのちが消えたりすると、風が吹いて次の種まきが始まります。
- 種まきのたびに、ししおどしが「カコーン」と鳴り、庭の苔がふるえます。
- ときどき、旅のグライダーが庭を横切ります。舞い落ちる花びらや葉は、地面に届くと種になります。
- 猫が庭を散歩したり、スズメが苔をついばみに来たりします。
- 季節は春・夏・秋・冬の4つで、朝・昼・夕・夜も移り変わります。最初は今の季節と時間帯から始まります。夜は石灯籠に灯りがともり、苔がホタルのように光ります。
- 画面をタップすると、その場所に種をまけます。
- 速さは「もっとゆっくり」から「もっとはやく」まで5段階です。
- 音はWebAudioで作った控えめな音で、初期設定はオフです。
- 外部ファイルやネットワーク接続は使いません。

画面をタップすると右下に設定ボタンが表示されます。
iPhoneではSafariで開き「共有」→「ホーム画面に追加」で全画面表示になります。
